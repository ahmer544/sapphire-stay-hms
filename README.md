# Sapphire Stay – Hotel Management System

## Overview
Sapphire Stay is a web-based hotel management system developed as a Computer Science Final Year Project for a functioning hotel in Muzaffarabad, AJK. It digitizes core hotel operations, automating room reservations, guest records, and administrative workflows.

## Key Features
* **Room & Reservation Management:** Real-time tracking of room availability, booking statuses, check-ins, and check-outs.
* **Administrative Control:** Secure management of guest records, billing transactions, and room configurations.
* **Role-Based Portals:** Dedicated interfaces tailored for hotel staff operations and customer booking needs.
